# Channel Delivery 2.1.0

Target **2.1.0** is an unpublished release candidate for the existing 2.x project line.
The published baseline is [2.0.0](2.0.0.md).

## Changes

- Reconnects on isolated worker sessions before a claim and between safe autocommit
  statements. A recovered status write after SMTP uses the original send.
- Automatically reclaims expired `processing` leases and settles exhausted attempts
  via email-delivery 1.3.0. The default lease is 300 seconds.
- Adds queue-stall monitoring and bounded exit for restart after consecutive database
  connection failures, plus alerts for unrecorded outcomes and exhausted leases.
  Retires the old scheduled stuck-job reset and checks for exhausted pending
  rows left by that reset before the worker can claim a job.
- Provides language-specific Twig brand globals and a compiled-cache clear command.
- Keeps v1 and v2 HTTP shapes, receipt identity, isolated synthetic recording and
  the previously supported PHP and PHPMailer lines.

## Upgrade

Deploy using the [2.1.0 upgrade guide](../upgrade/2.1.0.md). Service migration 003
already supplies the claim index for standard deployments. Coordinate worker
replacement, cache refresh and monitoring during the rollout.

The [checklist](RELEASE_CHECKLIST.md) records the evidence required for the final
main commit, registry publication and clean downstream installation.
