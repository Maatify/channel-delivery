# Code of Conduct — maatify/channel-delivery

[![Maatify Channel Delivery](https://img.shields.io/badge/Maatify-channel--delivery-blue?style=for-the-badge)](https://github.com/Maatify/channel-delivery)
[![Maatify Ecosystem](https://img.shields.io/badge/Maatify-Ecosystem-9C27B0?style=for-the-badge)](https://github.com/Maatify)

Be respectful and constructive in issues, reviews and discussions. Welcome different
backgrounds and experience levels; critique behavior and code rather than people.
Harassment, threats, discriminatory language, doxxing and disclosure of private
credentials or personal information are unacceptable.

Keep technical claims supported by reproducible evidence and respect project
scope/maintainer decisions. Report security concerns privately using [SECURITY.md](SECURITY.md).
Report community conduct concerns to [mohamed@maatify.dev](mailto:mohamed@maatify.dev).
Maintainers may moderate contributions to protect a respectful, safe project space.
